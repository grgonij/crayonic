HOW TO INSTALL (Windows)
========================

(If Windows blocked the zip: right-click the zip > Properties > tick "Unblock",
 then extract it again.)

1. Move the .vst3 folder into:
       C:\Program Files\Common Files\VST3
   (Windows asks for admin permission - that's normal.)

2. FL Studio: Options > Manage plugins > "Find installed plugins".
   The plugin is listed under Generators - add it to the Channel Rack.

The .exe is a standalone version you can run without a DAW.

Presets go in:  Documents\TEST\Presets
Presets that come with their own samples folder keep working - just keep
the preset and its samples folder together.

New to the plugin? "Quick Start Guide.pdf" explains every feature, with screenshots.
