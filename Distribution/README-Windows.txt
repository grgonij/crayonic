HOW TO INSTALL crayonic (Windows)
=================================

(If Windows blocked the zip: right-click the zip > Properties > tick "Unblock",
 then extract it again.)

1. Move the crayonic.vst3 folder into:
       C:\Program Files\Common Files\VST3
   (Windows asks for admin permission - that's normal.)

2. FL Studio: Options > Manage plugins > "Find installed plugins".
   crayonic is listed under Generators - add it to the Channel Rack.

crayonic.exe is a standalone version you can run without a DAW.

UPDATING FROM AN OLDER VERSION?
Close FL Studio first, then copy the new crayonic.vst3 in as above.
If you had a test version called TEST, delete TEST.vst3 from that same
VST3 folder - crayonic replaces it. Your presets and kits are carried
over automatically the first time you open crayonic.

KITS (presets + sounds)
In crayonic, click "kits" > "Import kit..." and pick the kit's zip.

New to crayonic? "crayonic Quick Start Guide.pdf" explains every feature, with screenshots.
